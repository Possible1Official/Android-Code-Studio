# CodeDeck Mobile

A professional mobile IDE for Android, built entirely from an Android phone.

## Features (Planned)
- Multi-language support with syntax highlighting
- Custom keyboard for coding
- Terminal integration
- Git support
- Code intelligence (LSP)
- Project management

## Development
This project is being developed 100% on Android using Termux.

## Current Status
